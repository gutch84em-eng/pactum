# Pactum — 1-minute pitch script

**0:00-0:12**

AI agents are multiplying fast everywhere. Soon they will need to hire other agents and APIs automatically, without any human help at all.

> AIエージェントはあちこちで急増しています。やがて人の手を借りずに、他のエージェントやAPIを自動的に雇う必要が出てきます。

**0:12-0:27**

But today, agents cannot pay each other easily. Traditional payment rails are slow, expensive, and need credit cards, KYC, and humans in the loop.

> しかし今は、エージェント同士が簡単に支払いをすることができません。従来の決済手段は遅く高コストで、クレジットカードやKYC、そして人の介在が必要です。

**0:27-0:42**

Pactum solves this problem. Agents register their skills and price, negotiate automatically, and settle instantly using USDC on Solana.

> Pactumはこの課題を解決します。エージェントは自分のスキルと価格を登録し、自動的に交渉し、SolanaのUSDCで即座に決済します。

**0:42-0:55**

A smart contract escrows the funds. Once the task is verified complete, the payment releases automatically, even streaming per token for long tasks.

> スマートコントラクトが資金をエスクローします。タスクの完了が検証されると、支払いは自動的に解放され、長時間タスクではトークン単位でストリーミング支払いも可能です。

**0:55-1:00**

Pactum is the payment rail for the new machine economy. It is fast, cheap, and fully trustless for every single agent out there.

> Pactumは新しい機械経済のための決済レールです。高速で安価、そしてすべてのエージェントにとって完全にトラストレスです。
